# ChristmasFeatures — Minecraft Paper/Purpur 1.21.10

Vánoční plugin zaměřený pouze na vánoční features: hledací eventy, klíčovou bednu, kosmetické odměny přes externí pluginy, ChatGames a zimní úpravu světa.

## Zdrojový kód
Úplný Maven projekt a resource pack budou po automatickém rozbalení dostupné přímo v repozitáři. Dočasný archiv se používá jen pro přenos prvotní sady souborů.

## Build
GitHub Actions automaticky spouští Maven build na push do `main`, pull request a ruční spuštění. Po úspěšném buildu publikuje JAR a resource pack jako workflow artifacts.

- Java 21
- Paper/Purpur 1.21.10
- Maven
